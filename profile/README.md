# SingNova

### A desktop AI development platform. Currently in development.

SingNova is a desktop AI development platform being developed by Nanyang Singtech.

We are exploring how local computing can support complex AI workflows—not only loading a model, but connecting models, data, tools, and applications into useful systems.

## What we are interested in

- Local language models and multimodal AI workflows
- Generative AI applications, including video generation
- RISC-V and dataflow computing
- Alternative AI computing platforms beyond NVIDIA
- Model deployment, inference optimization, and system integration

These are areas of development and discussion, not a list of verified capabilities or supported software.

## Current status

SingNova is currently in development.

We do not yet have public code, SDK downloads, or reproducible benchmarks available here.

As we publish technical materials, we will clearly distinguish verified results, work in progress, and future plans.
